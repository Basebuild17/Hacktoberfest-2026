# Security Policy

## Reporting a vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

If you believe you have found a security issue in this project, please report it privately through GitHub's security advisory process or by contacting the repository owner through a secure channel.

Please include:

- a clear description of the issue
- the affected files or behavior
- the impact of the vulnerability
- any reproduction steps or proof of concept if available

## Response expectations

We will review valid reports as quickly as possible and aim to provide an acknowledgement and next steps when a report is received.

## Supported versions

This project is a small static landing page, and support is focused on the current repository state on the default branch.

If a vulnerability affects an older version, we will evaluate whether a fix is practical and whether the change should be backported.
