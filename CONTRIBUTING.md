# Contributing

Thanks for your interest in contributing to this project.

## How to contribute

1. Fork the repository.
2. Create a branch for your work.
3. Make your changes and validate them.
4. Open a pull request with a clear description.

## PR checklist

- [ ] The change is clearly explained.
- [ ] Documentation is updated if needed.
- [ ] The project still works as expected.
- [ ] The PR is linked to the relevant issue when applicable.

## Community expectations

Please keep interactions respectful and constructive.
