# Hacktoberfest 2026

This website is a simple landing page for Hacktoberfest 2026.

## Local development

Open `index.html` directly in a browser or run a simple local server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deployment

This project can be published with GitHub Pages or any static hosting service.
